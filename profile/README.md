# 人工智能科技社

广西民族大学人工智能学院 · 人工智能科技社官方组织。

## 我们在做的事

- **研发部训练场**：以真实仓库 + 完整 PR 流程训练新成员的协作开发能力
- **竞赛项目孵化**：机器人、无人机、软件开发等方向的研发与沉淀
- **规范先行**：所有项目遵循 [guidelines](https://github.com/GXMZU-AITECC/guidelines) 协作规范

## 新成员从这里开始

1. 📖 通读 [guidelines](https://github.com/GXMZU-AITECC/guidelines)（开发规范 / PR 规范 / Repo 规范 / 权限规则）
2. 🎯 在训练场仓库 [calculator-js-web](https://github.com/GXMZU-AITECC/calculator-js-web) 的 Issue 列表认领入门任务
3. 🔀 fork → `feature/...` 分支 → 向 `develop` 提 PR → 接受 review
4. ✅ 通过考核后加入组织，正式参与项目研发
